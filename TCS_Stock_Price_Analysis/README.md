# TCS Stock Analysis Dashboard 📊

A comprehensive Power BI dashboard for analyzing Tata Consultancy Services (TCS) stock performance on the National Stock Exchange (NSE).

<img width="2000" height="1156" alt="image" src="https://github.com/user-attachments/assets/e1afc5e2-f415-4162-b7ce-093d94fd6898" />


## 📈 Overview

This Power BI project provides real-time insights and historical analysis of TCS stock performance, featuring interactive visualizations for traders and investors to make informed decisions.

## ✨ Key Features

### Real-Time Stock Metrics
- **Live Price Tracking**: Current stock price with real-time updates
- **Day Trading Metrics**: Open, High, Low, LTP (Last Traded Price), and VWAP
- **52-Week Range**: Historical high (₹4,592.25) and low (₹2,866.60) tracking

### Trading Analytics
- **Volume Analysis**: Total trading volume (671M shares)
- **Trade Value**: Market value tracking (2.25T)
- **Trade Count**: Number of executed trades (38M)
- **Series Information**: Stock series classification (EQ)

### Interactive Visualizations
- **Stock Price Trends**: Quarterly stock price movement analysis
- **Volume Patterns**: Trading volume distribution across quarters
- **Trade Activity**: Number of trades visualization by quarter
- **Historical Timeline**: Year-over-year performance from 2020-2025

### Latest News Integration
- Real-time news feed from multiple sources
- Timestamp tracking for market-moving events
- Coverage from Moneycontrol, Goodreturns, India Today, and regional sources

## 🎨 Dashboard Components

### Stock Information Panel
- 52-Week High/Low indicators
- Current session Open and Low prices
- Last Traded Price (LTP)
- Volume Weighted Average Price (VWAP)

### Trading Metrics Panel
- Daily volume statistics
- Total value traded
- Number of trades executed
- Stock series classification

### Visualizations
1. **Stock Price by Quarter**: Line chart showing quarterly price trends
2. **Volume by Quarter**: Bar chart displaying trading volume patterns
3. **Number of Trades by Quarter**: Bar chart showing trade frequency

### News Feed
- Chronological display of latest market news
- Multi-source aggregation
- Relevance filtering for TCS-specific updates
